## 知识库

### KITLAMT 独立站部署

```bash
# 部署命令
ssh -p 8888 root@45.77.175.209 '/var/www/kitlamparts/deploy.sh'

# 文件上传（SSH被阻断时用HTTP代理）
curl -s --data-urlencode "p=path/to/file.html" \
  --data-urlencode "c=$(base64_content)" \
  http://45.77.175.209/d.php

# VPS nginx 根目录
/var/www/html/  # 不是 /var/www/kitlamt-website/
```

### Xray VLESS Reality 配置

```json
{
  "inbounds": [{

    "protocol": "vless",

      "decryption": "none"
    },
    "streamSettings": {
      "network": "tcp",
      "security": "reality",
      "realitySettings": {
        "dest": "www.microsoft.com:443",
        "serverNames": ["www.microsoft.com"]
      }
    }
```

## 技术博客

### 从 0 到 1 搭建外贸 B2B 独立站

**技术选型**：
- 不用 Shopify/WooCommerce — 太模板化，不适合汽配行业
- 选 PHP + MySQL — 简单直接，VPS 性能够用
- 前端纯 JS — 1084 个 SKU 不需要 React/Vue

**核心设计决策**：
1. **数据源单一**：`partsDB.js` 是唯一数据源，前端直接读 JSON
2. **询盘优先**：大部分商品无标价，走 WhatsApp 询盘
3. **支付双通道**：Stripe（有标价）+ WhatsApp（无标价）
4. **双语**：中英文，localStorage 持久化语言选择

**上线后待办**：
- PayPal 商户账户解除限制
- 域名 + SSL 证书配置
- SEO 优化（后续做了 GSC 提交）
