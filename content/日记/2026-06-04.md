## 知识库

### Windows 符号链接创建

```powershell
# 创建目录符号链接
cmd /c mklink /D "C:\Users\Lenovo\Documents\WXWork" "D:\Documents\WXWork"

# 验证链接
dir "C:\Users\Lenovo\Documents\WXWork"
# 应该显示 <SYMLINKD>
```

### C 盘空间分析

```powershell
# 查看各目录大小
Get-ChildItem "C:\Users\Lenovo" -Directory | ForEach-Object {
    $size = (Get-ChildItem $_.FullName -Recurse -Force -ErrorAction SilentlyContinue |
        Measure-Object -Property Length -Sum).Sum
    [PSCustomObject]@{
        Name = $_.Name
        SizeGB = [math]::Round($size/1GB, 1)
    }
} | Sort-Object SizeGB -Descending
```

### 默认安装路径修改

```powershell
# 修改注册表默认安装路径
Set-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion" `
    -Name "ProgramFilesDir" -Value "D:\Program Files"
```

## 技术博客

### Windows C 盘空间管理策略

**预防措施（定期执行）：**
1. 每月清理一次 Temp 文件夹
2. 浏览器缓存设置上限（Chrome → 500MB）
3. Downloads 文件夹定期清理
4. 回收站设置 7 天自动清空

**迁移策略：**
1. 大文件夹（微信、企业微信）→ 迁移到 D 盘 + 符号链接
2. 开发工具缓存（npm、pip）→ 配置到 D 盘
3. 桌面大文件 → 定期归档到 D 盘

**安装路径规范：**
- 新软件默认安装到 D:\Program Files
- 开发工具（Node.js、Python）默认到 D 盘
- 游戏/大型软件必须到 D 盘

**监控：**
- 设置 C 盘空间告警（剩余 <50GB 时提醒）
- 定期用 `TreeSize` 或 `WizTree` 扫描大文件夹
