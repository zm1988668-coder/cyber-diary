## 个人复盘

今天做了两件跨领域的事：汽配系统 Electron 化和赛博日记搭建。

Electron 化是为了让汽配系统能在桌面运行，不依赖浏览器。加了权限管理（RBAC）是为多用户场景做准备——汽配店老板、仓管、销售不同角色看到不同内容。

赛博日记是个人项目，选 Quartz 是因为它够轻量、够灵活。GitHub Pages 免费部署，Actions 自动构建，几乎零成本运营。

WhatsApp 获客的反馈很关键——之前获客只收集公司名和电话，但外贸场景下 WhatsApp 才是核心沟通工具。这个认知改变了后续所有获客任务的数据结构。

### GitHub Actions 部署

```yaml
# .github/workflows/deploy.yml
name: Deploy to GitHub Pages
on:
  push:
    branches: [main]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm ci && npx quartz build
      - uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./public
```

## 技术博客

### 为什么选 Quartz 而不是其他 Digital Garden 工具

对比了几个主流方案：

| 工具 | 优点 | 缺点 |
|------|------|------|
| Quartz | 轻量、Markdown原生、GitHub Pages友好 | 需要Node.js环境 |
| Obsidian Publish | 界面好看 | 付费（$8/月） |
| TiddlyWiki | 极其灵活 | 学习曲线陡峭 |
| Notion | 协作好 | 不是静态站、SEO差 |

Quartz 的核心优势：
1. **Markdown 即内容**：不需要数据库，纯文件管理
2. **GitHub Actions 自动部署**：push 就构建，零运维
3. **可定制**：主题、字体、布局都能改
4. **免费**：GitHub Pages 免费托管
