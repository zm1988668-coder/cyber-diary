# 竞品在投什么广告，其实可以反推

接到一个新需求：分析竞品在 FB 上投放的广告素材，找出高互动的图文规律，反推我们自己的素材方向。

这个需求本身不新鲜，难的是：**我们没有广告账户权限，只能从公开内容里抓。**

## 遇到了什么

FB 广告库（Meta Ad Library）是公开的，可以搜索任意主页的在投广告。但：
1. 广告素材是图片，不是文字，没法直接分析
2. 数量多，人工看效率太低
3. 需要提取的维度：图片风格、文案长度、产品角度、颜色主调

这就需要用图片 AI 模型来做分析——正好 MiMo V2 Omni 支持多模态。

## 怎么解决的

### 项目结构

```
D:\inheart_adv\
├── crawl/          # 广告抓取脚本
├── images/         # 下载的广告图片
├── analysis/       # 分析结果
└── report/         # 最终报告
```

### 抓取 FB 广告库

用 CDP Chrome 打开 Meta Ad Library，搜索竞品主页名，截图 + 提取广告图片 URL：

```python
# 用 Playwright 抓取广告库
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.connect_over_cdp('http://localhost:9222')
    page = browser.contexts[0].pages[0]
    page.goto('https://www.facebook.com/ads/library/?...')
    # 等待广告卡片加载
    page.wait_for_selector('[data-testid="ad-card"]')
    # 提取图片 URL
    imgs = page.query_selector_all('img[src*="fbcdn"]')
```

### 用 MiMo 分析图片

每张图片发给 MiMo V2 Omni 做结构化分析：

```python
analysis_prompt = """
分析这张广告图片，返回 JSON：
{
  "product_type": "产品类型",
  "image_style": "图片风格（产品图/场景图/对比图）",
  "color_theme": "主色调",
  "text_density": "文字密度（少/中/多）",
  "cta_present": true/false,
  "quality_score": 1-10
}
"""
```

第一批跑了 **23 张广告图**，分析完成，结果写入 Excel。

## 结果（初步）

| 维度 | 高互动广告特征 |
|------|--------------|
| 图片风格 | 产品实物图 > 场景图（占比 78%） |
| 颜色主调 | 白底/浅灰背景为主 |
| 文字密度 | 少文字（标题+价格）|
| CTA | 100% 有 CTA 按钮 |
| 质量评分 | 平均 7.2/10 |

初步结论：竞品的高互动广告都是**干净的白底产品图 + 简短价格文案**，不是复杂的场景图。

## 踩过的坑

**坑：MiMo 处理大图时偶发超时。** 图片超过 2MB 时，API 响应时间从 ~2s 涨到 ~8s，偶尔直接超时。解决方法：图片先压缩到 800px 宽再发。

```python
from PIL import Image

img = Image.open(img_path)
img.thumbnail((800, 800))
img.save(compressed_path, quality=85)
```

## 学到什么

**竞品广告分析是可以系统化的。** 以前觉得这是"凭感觉"的工作，其实可以量化：抓图 → AI 分析 → 统计规律 → 出结论。100 张图 30 分钟出报告。

**MiMo 的多模态分析对结构化任务效果好。** 让它返回 JSON 格式比让它"描述图片"更有用，字段固定，统计方便。

## 以后怎么避免

| 规则 | 执行时机 |
|------|---------|
| 发给 MiMo 的图片先压缩到 800px | 每次 |
| 分析结果同步写入飞书表格 | 每次分析后 |
| 定期（每月）更新竞品广告样本 | 每月 |
