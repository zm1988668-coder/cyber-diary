# 同一个产品，在不同国家卖的是完全不同的规格

最近在整理南美市场的方向机型号需求，发现一个有意思的规律：**同一款车（比如丰田 Hilux），巴西卖的和阿根廷卖的，转向机型号完全不一样。**

不是小差异，是完全不同的零件编号。同一辆车，因为组装工厂不同、市场导入时间不同，零件体系就不一样。这对选品和报价影响很大。

## 遇到了什么

手头有客户问了几款热卖型号，但我们的产品目录是按品牌分类的，不是按国家/车型分类的。要回答"巴西市场哪些方向机卖得好"，得交叉查好几张表。

做了三件事：
1. 整理了"国家热卖型号"目录
2. 做了"南美洲筛选"数据集
3. 把两个结果和产品数据库对比，找出我们有货的型号

## 怎么解决的

### 按国家整理热卖型号

从客户问询记录、外贸通数据和自己积累的经验，整理出南美主要国家的热销方向机型号：

| 国家 | 热销车型 | 方向机型号 |
|------|---------|-----------|
| 巴西 | VW Gol, Fiat Uno, GM Celta | LHD 电动助力 |
| 阿根廷 | Toyota Hilux, Ford Ranger | RHD/LHD 液压 |
| 墨西哥 | Nissan Tsuru, VW Jetta | LHD 机械 |
| 智利 | Toyota Land Cruiser | RHD 液压 |
| 秘鲁 | Toyota Hiace, Coaster | RHD 液压 |

这是初版，后续会继续补充。

### 数据匹配脚本

用 Python 把这个型号表和产品数据库做了一次匹配：

```python
hot_models = pd.read_excel('国家热卖型号.xlsx')
products = pd.read_excel('db_products.tsv', sep='\t')

# 模糊匹配车型名
from fuzzywuzzy import fuzz

def match_product(model_name, products_df):
    scores = products_df['model'].apply(
        lambda x: fuzz.partial_ratio(model_name.lower(), str(x).lower())
    )
    best_idx = scores.idxmax()
    if scores[best_idx] > 70:
        return products_df.loc[best_idx]
    return None
```

匹配结果：热卖型号 42 款，我们有现货或可采购的 **31 款（74%）**。

## 结果

| 指标 | 数值 |
|------|------|
| 整理热卖型号 | 42 款 |
| 有货匹配率 | 74%（31/42） |
| 可直接报价 | 26 款 |
| 需要采购确认 | 5 款 |
| 暂无货 | 11 款 |

## 踩过的坑

**坑：车型名称在不同数据源里写法不一致。** 有的写"Land Cruiser"，有的写"Landcruiser"，有的写"LC200"。模糊匹配可以解决大部分，但需要人工复核边界情况（匹配度 60-80% 的那些）。

## 学到什么

**按市场整理产品，比按品牌整理产品更接近客户的思维方式。** 客户问的是"巴西市场什么卖得好"，不是"ZF 品牌有什么型号"。产品目录要能从两个维度查：按品牌 + 按市场。

## 以后怎么避免

| 规则 | 频率 |
|------|------|
| 热卖型号表按季度更新 | 每季度 |
| 新客户问询时同步更新市场数据 | 实时 |
| 模糊匹配结果 70% 以下的手动复核 | 每次匹配后 |
