# 电脑太卡了——一次彻底的C盘清理

开机要等 **2 分钟**。不是那种"喝口水就过去"的 2 分钟，是那种"打开手机刷两条消息回来还在转圈"的 2 分钟。

16GB 内存，开机后直接被吃掉 **12GB**（75%）。Clash 200MB、飞书 500MB、向日葵 300MB——这三个家伙光自启动就吞掉 **1GB**。剩下的 4GB 给 Chrome 和系统抢着用。

忍了好久了，今天终于动手。

## 先看看病根在哪

C 盘：**300GB 的盘，只剩 72GB，用了 76%。**

用 WizTree 扫了一遍，元凶一目了然：

| 文件夹 | 大小 | 说明 |
|--------|------|------|
| AppData | 63 GB | 各软件缓存（Chrome 10GB、Edge 5GB、WPS 6GB） |
| Documents | 24 GB | 企业微信 19GB + 微信 5GB |
| .openclaw | 12.9 GB | 平台数据 |
| Downloads | 4.6 GB | 一堆旧安装包 |

然后看了一眼自启动——**11 个程序**抢着在开机时跑。

## 开刀

### 第一刀：关自启动

打开注册表 `HKCU:\...\Run`，把 Clash、飞书、向日葵三个干掉。

```powershell
Remove-ItemProperty -Path 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' -Name 'com.lbyczf.clashwin'
```

**效果：** 开机少了三个常驻内存的家伙，内存占用从 12GB 降到 ~11GB。立竿见影，但还不够。

### 第二刀：清缓存

| 清理项 | 清理前 | 释放 |
|--------|--------|------|
| Temp 文件夹 | 4.9 GB | **4.9 GB** |
| Chrome 缓存 | 10.3 GB | **~8 GB** |
| Edge 缓存 | 4.8 GB | **~3.8 GB** |
| 回收站 | 1.2 GB | **1.2 GB** |

一波清了 **~18 GB**。Chrome 一个缓存就 **10.3 GB**——比我所有文档加起来还多。浏览器会无限缓存，但从不自动清理。这个设计真的挺鸡贼的。

### 第三刀：搬家（最难的部分）

真正的大头是企业微信（19.1GB）和微信（5.2GB）的聊天记录。**24.3 GB** 堆在 C 盘的 Documents 里。

问题是：这两个软件的存储路径写死在配置里，直接改路径容易出 bug。

我想到了一个方案——**符号链接（symlink）**。

```powershell
# 1. 把文件搬到 D 盘
Move-Item "C:\Users\Lenovo\Documents\WXWork\*" "D:\Documents\WXWork"

# 2. 删掉原目录
Remove-Item "C:\Users\Lenovo\Documents\WXWork" -Recurse -Force

# 3. 在原位置建一个"传送门"
cmd /c mklink /D "C:\Users\Lenovo\Documents\WXWork" "D:\Documents\WXWork"
```

为什么要这样做？因为符号链接对应用来说是**透明的**——企业微信打开 `C:\...\WXWork`，操作系统会自动重定向到 `D:\Documents\WXWork`。应用完全不知道你搬了家。

迁移完打开企业微信试了一下——**聊天记录全在，直接能用，零报错。** 这感觉就像给房子换了个地址，但门牌号没变，邮递员还是能送到。

## 结果

| 指标 | 清理前 | 清理后 | 变化 |
|------|--------|--------|------|
| C 盘剩余 | 72 GB | 114.7 GB | **+42.7 GB (+59%)** |
| 开机自启动 | 11 个 | 8 个 | **-3 个** |
| 开机内存占用 | 12 GB (75%) | ~8 GB (50%) | **-4 GB** |
| 开机时间 | ~2 分钟 | ~40 秒 | **-80 秒** |

## 踩过的坑

**坑1：PowerShell 变量被吞。** 在 Claude Code 里跑 PowerShell 命令，`$` 符号会被 shell 解释掉，变量全变成空。解决办法：把脚本写到 `.ps1` 文件再执行，不在命令行里内联写。

**坑2：符号链接需要管理员权限。** `mklink /D` 在普通 PowerShell 里能跑，但如果目标目录在系统盘，可能需要管理员权限。我这次是在用户目录下创建的，没遇到问题。

**坑3：默认安装路径改了但不生效。** 改了注册表的 `ProgramFilesDir`，但很多安装程序会自己检测并覆盖。只有新安装的软件才会用新路径。已装的软件不受影响。

## 学到什么

**符号链接是迁移神器。** 很多软件把路径写死（微信、企业微信都有这毛病），用 `mklink /D` 可以绕过限制。这次迁移了 **24.3 GB**，应用零感知。

**自启动是内存黑洞。** 11 个自启动，3 个重型应用吃掉 **1GB**。以后每装 3 个新软件就检查一次 `msconfig`。

**别等到 76% 才动手。** SSD 在高占用下写入性能会下降 10-20%。C 盘低于 **60%** 就该清理了。

## 以后怎么避免

| 规则 | 频率 |
|------|------|
| WizTree 扫描 C 盘，找 >2GB 的文件夹 | 每月 |
| 清理 Temp + 浏览器缓存 | 每月 |
| 检查自启动项 | 每装 3 个新软件 |
| 清理 Downloads 旧安装包 | 每月 |
| 新软件一律装 D 盘 | 每次安装 |
