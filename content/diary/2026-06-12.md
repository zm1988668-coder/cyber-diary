# Google 说我的页面"已发现但未编入索引"——这是什么意思

昨天提交了 IndexNow，今天打开 GSC 继续看报告。结果看到一个状态让我愣了一下：**"已发现 - 目前未编入索引"（Discovered - currently not indexed）**。

这和"未提交"不一样，也不是"被屏蔽"——Google 知道这些页面的存在，就是不愿意收录。

## 问题诊断

GSC 报告显示：
- 已编入索引：89 个
- **已发现但未索引：103 个**
- 被屏蔽（robots.txt）：0
- 被 noindex：0

103 个页面 Google 看到了，但跳过了。原因通常是：
1. **页面质量低**：内容太少或太相似
2. **内链薄弱**：没有其他页面链接到这些页面，Google 认为不重要
3. **加载太慢**：Core Web Vitals 不过关

逐一排查：

### 检查内链

用工具扫了一下独立站的内链结构，发现问题：**大量产品页是孤立页面（Orphan Pages）**，除了 Sitemap，没有任何内部链接指向它们。

Google 的爬虫逻辑是顺着链接走，没有链接指向的页面，优先级就低。

### 修复内链

在品牌页面、分类页面、首页添加了指向产品页的链接：

```html
<!-- 在品牌页底部添加相关产品 -->
<section class="related-products">
  <h3>Toyota 转向系统产品</h3>
  {products.map(p => (
    <a href={`/products/${p.slug}`}>{p.name}</a>
  ))}
</section>
```

同时在每个产品页添加"同品牌其他产品"的推荐区。

**修复前：平均每个产品页有 0.3 个内链指向它。**
**修复后：平均 2.1 个。**

### 检查页面质量

发现 37 个产品页的描述文字少于 100 字，属于"内容单薄页面"。Google 对这类页面的收录意愿很低。

批量补充了描述，用 Claude 辅助生成标准化的产品描述模板：

```
[产品名称] 适用于 [车型]，采用 [规格参数]。适合 [目标市场] 市场，OEM 品质，支持 [MOQ] 起订。
```

## 结果

| 指标 | 修复前 | 修复后（预估） |
|------|--------|--------------|
| 孤立产品页数量 | 103 | ~20 |
| 平均内链数 | 0.3 | 2.1 |
| 内容少于100字页面 | 37 | 0 |

收录结果需要 1-2 周才能反映在 GSC 上。

## 踩过的坑

**坑：批量添加内链时不小心给所有产品页加了指向自身的链接。** `<a href="/products/abc">` 放在 `/products/abc` 页面上，产生了自引用链接。虽然不影响排名，但很蠢。加了条件判断过滤掉。

## 学到什么

**孤立页面是 SEO 的隐形杀手。** 建站时只想着"把产品放上去"，没想到内链结构。Google 会把没有内链的页面视为"不重要的内容"，宁可不收录。

**"已发现但未索引"是可以修复的状态，不是死刑。** 对症下药：内链薄弱补内链，内容单薄补内容。

## 以后怎么避免

| 规则 | 频率 |
|------|------|
| 新建页面同时检查有无内链指向它 | 每次发布 |
| GSC "已发现未索引"报告每周看一次 | 每周 |
| 产品页描述最少 150 字 | 每次录入 |
